# Midnight Glass AI Assistant

An advanced, AI-powered companion application featuring a "Midnight Glass" aesthetic with deep obsidian dark mode, glassmorphism panels, and bioluminescent accents.

## Features

*   **Home Dashboard**: Quick-action cards for Dropping Photos, Breathing Exercises, and quick access to the Memory Vault.
*   **Chat Interface**: Real-time text streaming with distinct font styling for *actions* versus spoken dialogue, featuring a pulsing "breathing" typing indicator.
*   **Soul Forge (Settings)**: A dedicated settings tab with sliders for Affection Intensity, Authority Level, and a Rule Builder for Image Reactivity.
*   **Memory Vault**: A visual timeline of interactions and a media gallery for uploaded photos.

## Tech Stack

*   Flutter (Cross-platform compatibility for iOS, Android, Web, and Desktop)
*   Provider (State management)
*   Google Fonts (Custom typography)

## Setup and Run Instructions

1.  Make sure you have Flutter installed.
2.  Clone the repository and run `flutter pub get` to install dependencies.
3.  Run the app with `flutter run`.
